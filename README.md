# 💫 About Me:
I’m a developer who enjoys building things, breaking them, figuring out why they broke, and making them better. My primary focus is backend development with Java and Spring Boot, with hands-on experience working with REST APIs, Microservices, Kafka, databases, and real-time applications. I’m currently learning more about cloud infrastructure, distributed systems, Kubernetes, Redis, and system design. I believe the best way to learn technology is to build with it, so most of my learning happens through projects and experimentation.
